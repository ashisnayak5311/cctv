CCTV Live View

Connect a second laptop in Local mode

Start the server with .\start-cctv-https.ps1 on this laptop. Copy %USERPROFILE%\.cctv\local-development.cer to the second laptop and import it into the Current User Trusted Root Certification Authorities store. Then open https://SERVER-IP:8443/camera-sender.html. The browser will prompt to allow camera access.

This development certificate is for your trusted local network only. Detailed certificate import and IP-change steps are in the project HELP.md.
